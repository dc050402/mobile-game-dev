# Data-Use and Privacy Statement

This game does not collect, store, or share personal information from players.

The game does not require an account and does not request personal information such as a player's name, email address, contacts, location, camera, or microphone data.

Gameplay is processed locally on the Android device. The game does not intentionally transmit player data to external servers.

Unity Profiler and Android Logcat were used during development and testing to monitor the game's performance and runtime behaviour. These development tools are not part of the game's player-facing data collection.

The game does not use third-party advertising or analytics services.
